# Algo Atlas 产品与验收计划

2026-10-30，Stage 001 功能与本地验证完成；Stage 002 光影运动升级完成。远端发布状态见阶段日志。

中文优先、无需账号即可使用的算法与数据结构学习工作台。桌面和手机共享同一知识模型；MIT 开源，不依赖公司工程。

## 范围

分层知识目录，涵盖常见数据结构、排序搜索、图、动态规划与问题求解、字符串、数学与几何。每项提供介绍、发展背景、用途、复杂度条件、误区、可回放实验与练习。复杂结构采用明确标注的机制实验，不能把机制示意冒充完整工业实现。

搜索匹配中文、英文与关键词；收藏、笔记、完成状态持久化到本机；分享只包含课程和实验参数，不包含私人笔记；支持数据导入导出。预留版本化在线服务契约，不伪装已上线的账号或同步服务。

## 验收

- 目录无空内容，无无响应按钮；难度/重要性/常用度说明为编辑评级，不能声称实时统计。
- 真实算法轨迹可播放、暂停、回退、调速、定位；明确输入规模和适用条件。
- 单元验证排序、搜索、图、DP 和数据导入边界；桌面/移动浏览器检验学习、搜索、收藏、笔记、分享。
- npm 构建通过；MIT、README、开发说明、测试证据与后续边界齐全后推送 ax2 的公共仓库。

“所有常见”按版本化覆盖清单管理，不能声称穷尽计算机科学的所有算法。后续新增主题遵循同一内容契约。
