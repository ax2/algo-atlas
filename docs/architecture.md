# 架构与关键决策

## 内容与运行分离

Topic 只描述课程与输入协议；runTrace 依据分类派发到基础、进阶结构和 AI 纯函数引擎。引擎返回 `Trace {frames,kind,result,caption}`，Frame 表示数组、节点/边、矩阵中的一种或数种状态。Diagram 按帧实际字段选择渲染器，因此同一图课可以在图与距离矩阵之间切换。

所有帧写入时 structuredClone，播放器只持有输入、目标、当前索引、播放状态与速度。播放器不会在暂停/回退时重新随机运行算法。轨迹通过 useMemo 在输入或课程改变时计算，定时器在卸载时清理。

## 有限输入与安全计算

数字序列默认最多 16 项且每项 0–99；字符串限定英文字母；图固定 6 点，4 皇后固定小棋盘。上限与提示一致，特殊课另设范围。帧上限 5,000，防止无边界回溯或巨大输入冻结 UI。此规模无需 Worker；若扩展输入应使用惰性轨迹/Worker，不应简单提高上限。

## 本地优先

学习状态采用版本化 JSON，外部导入经 validateLearning 校验已知课程 ID、字段类型、长度与文件大小。合并不删除现有收藏/完成状态；同课不同笔记并排保留，合并超限则整次拒绝。React 文本节点渲染笔记，不使用 HTML 注入。

分享 URL 仅包含非私密实验状态，hash 路由避免后端路由依赖。localhost 链接不能跨设备访问，UI 有明确提示。公共静态托管后，链接可在其他设备还原。

## 交互与可访问性

所有主控件有可访问名称，实验图单元可聚焦/点击；SVG 图附文本说明；时间轴是原生 range。对话框使用 aria-modal、Esc 关闭、首尾焦点循环与关闭后焦点恢复。深浅主题存本地；响应断点将侧栏折为抽屉、解释面板移至下方。禁用 reduced-motion 时不播放额外装饰动画。

## 当前取舍

- 使用完整帧换取任意回退；这是播放器成本，不作为算法复杂度。
- 内容本地随版本发布，尚无 CMS、账号和云同步。
- 图与复杂树采用有限精选机制场景，强调规则而非图编辑器。
- 源码页展示真实引擎模块，包括绘图轨迹辅助代码，方便与运行结果对应。
- 不引入第三方统计、广告或外部字体请求。

## Stage 003 的内容与讲解契约

Frame 增加 explanation、checkpoint、inputState，Trace 增加 source。讲解器只使用已计算轨迹和对应机制规则，不臆测下一次数据；播放器使用 setTimeout，在关键帧到达时暂停。完整树的指针变更先接回根，再生成帧；旧快照仍不可变。

题库使用稳定 Problem.id 与 topic 标签，独立列表/详情路由、分页、筛选和分层揭示题解。参考函数单独维护，源码摘取与测试运行指向同一文件；换行标准化使 Windows checkout 的 CRLF 不影响代码展示。LearningData v1 可选 exerciseCompleted 字段向后兼容，导入校验并合并已知题目 ID。

## Stage 004 · AI 训练轨迹

`autodiff.ts` 提供小型标量反向自动微分，拓扑逆序累加共享路径梯度；每轮重建计算图、同步 SGD 更新。`ai-models.ts` 实现 MLP 和 Pre-LN 双头因果 Transformer，不依赖 ML 服务或外部模型。`ai-labs.ts` 在计算后只保存数值、参数账本、说明与图状态，不保留历史计算图。RL 独立使用确定性 PRNG 和表格 Bellman 更新，终止/截断分开处理。

`AILab` 按配置 useMemo 重算，播放只改变快照索引。配置变更回到首帧，关键阶段暂停；URL 参数带边界校验，可还原配置与步骤。张量观察与参数组筛选不改变算法。复用 Diagram 的光影和系统减少动态效果。Problem.caseId 让练习详情可返回对应综合实验；学习存储版本不变。

新增实验中的表格更新和神经元数值来自真实结果。Transformer 反传图从损失开始，不将离散 Token 或优化器画成梯度来源。回放快照开销单独于算法复杂度说明。


## Stage 008 · 综合专题的固定视口

AI 实验复用课程的 `FitDiagram` 与 `AdaptiveNotes`：图形按真实内容边界缩放，说明按照实际排版测量分页。`AITensor` 使用容器与表头的 ResizeObserver 计算行列窗口，保留原始索引与完整精度检查；不改变数值引擎。参数聚焦等式与主图同屏，完整账本按参数组过滤和分页，前向的未计算梯度显式标记。趋势视图的监督学习横轴从更新次数 0 开始（初始损失），强化学习从已完成回合 1 开始。六个常规专题复用固定视口和解释分页，保留方案比较语义。

## Stage 009 · 图示与数值的语义关联

`DiagramSelection` 保存节点 ID 或边的端点，`ai-links.ts` 将其解析为真实张量切片和参数名；选中身份不依赖图中文字或前后传方向。`ai-inspection-data.ts` 集中生成数值目录，帧只引用已经计算的阶段；SGD 更新帧再以前后参数分别前向计算，保存 `beforeRows` 和 `changed`，不保留自动微分图。梯度属于更新前的损失，更新后张量显式注明这一点。

神经网络边映射到精确的 W1/W2 元素；Transformer 边表示算子之间的数据流，关联目标算子的参数组，不把注意力概率当作可训练权重。表格 Q-learning 的方向标为 −TD，写入高亮仅作用于实际状态动作对；零增量仍可定位，但不伪装成数值变化。

联动面板继续使用按容器宽高分页的 `TensorView`，以张量名称保留选择，避免阶段添加新张量后索引错位。参数行可联动主图下方的更新等式；普通观察面板不改变所选图对象。SVG 连线使用扩大的透明点击区域，支持 Enter/空格，更新颜色在减少动画模式下仍保留。

## Stage 010 · 反向关联与推导

`Tensor.ref` 携带稳定语义键；切片保留原行列映射。`ValueSelection` 描述原始坐标或参数与字段，`ai-calculation.ts` 返回相关节点/边、计算说明及当前更新项。当前阶段可见性仍由帧决定；只有点选时才重建小模型核对中间值。自动微分的可选 observe 回调收集参数的真实局部贡献，默认反传语义与数值不变。Transformer 导出额外数值中间量以解释 LayerNorm/FFN，不持久化 Scalar 图。

推导覆盖原观察面板内容，原表格保持挂载，隐藏时不测量零尺寸；`AdaptiveNotes` 根据实际排版分页。参数账本的 action 使用稳定参数名与 before/gradient/after 字段，测量层与显示层具有一致按钮几何。图高亮支持多个节点/边，正反向传播时边身份按端点匹配；Q 历史推导不会冒充当前写入等式。配置变化清除反向选择，阶段变化按同一语义引用重新计算并区分待计算/预览/实际更新。

## Stage 012 · 反传路径与本地化

`calculationSteps` 按所选参数的依赖可达性过滤实际反向遍历事件，保留从 loss 到参数的完整路径，每个事件生成 derivative/mul/add 三步；中间标量继承其命名张量的算子与样本归属，常量不错误关联选中权重。每个累计值都来自该条贡献写入后的真实 Scalar.grad。参数更新仍独立于反传。

`src/i18n` 提供 React JSX runtime 与 zh/en locale store。文本、展示属性与可访问名称在渲染前本地化；value、data-*、函数参数与用户文本不变。测量型布局显式先翻译后分页/计算边界。词条由 TypeScript AST 提取，稳定数字 ID 防止新增文本改变旧映射；测试同时检查静态词条、动态算法帧和实际浏览器页面。

Stage 013 将中文统计属性名也纳入提取。`scripts/localize-engine.mjs` 在构建维护流程中使用同一词典转换引擎源码的字符串、模板及展示属性名，输出英文教学视图；运行时只选择静态内容，实际计算引擎不替换。检查拒绝过期生成文件、无法转换的标识符或中文残留。长文字分页在测量上限内优先选择英文词边界；SVG 标签按两行中的最长行测量宽度。

## Stage 011 · 计算微步骤

`Scalar` 为运算保留类型与局部导数，模型的 `inspect` 字段把张量坐标关联到真实计算节点。`ai-calculation-steps.ts` 在点选时重建相应参数快照，遍历当前输出的运算图；命名张量作为输入边界，FFN 激活与词表投影继续展开。步骤只保存数值和语义引用，不将 Scalar 图放进历史帧。不解析舍入后的文案，也不为展示重复执行参数更新。

参数回放使用反向遍历的真实上游梯度与局部导数，逐次乘法/累加后再演示学习率乘法和 SGD 写入。Q 回放使用真实 transition，保留终止不自举、待写入与历史写入的区别。神经网络每个贡献沿用对应样本的输入与激活，反传边按方向翻转；中间结果标明“本步”，不会冒充完成后的激活。

`CalculationPlayer` 在固定观察区域中只显示本步的至多四个输入/结果单元格；公式通过稳定 cell ID 对应坐标和值。`AILab` 为微时间轴单独存储播放状态，键由配置、训练位置及所选值组成；跨阶段重置并暂停。微播放暂停训练时间轴，主播放暂停微时间轴。关闭、换选项或切回完整推导会清除计时器。短屏优先保留控制、公式、单元格和进度，完整说明可切回原推导；没有内部滚动容器。
