# Stage 012 · 逐层反向传播与英文支持

## 实现

- 参数的逐步演示从 `∂L/∂L=1` 开始，沿真实 Scalar 计算图中所有通向所选参数的路径逆拓扑回传；每条依赖拆成局部求导、上游梯度乘局部导数、已有梯度加本路贡献三个步骤。
- 明确显示上游梯度、局部导数、本路贡献、已有累积、累计梯度。共享参数跨样本、位置和分支的贡献逐次相加，最后才演示学习率乘法和参数写入。回放不重新训练，不修改历史帧。
- 临时量定位到实际所属算子；跨算子贡献同步点亮对应节点和反向连线。局部导数标为 `∂v/∂u`，贡献标为 `δ∇`，累积标为 `∇`，避免混淆三种数值。
- 融合交叉熵直接回传到 logits，残差直接跨层回传；缺失的直连边按当前计算依赖临时绘制，不能用概览图最短路径绕经无关算子。
- 增加反传层级定位。保留独立暂停、前后单步和时间轴；点击步骤公式标题可阅读该步的详细说明，自动分页且不增加内部滚动条。
- 新增中文/英文切换，选择存入独立的 `algo-atlas.locale`。翻译覆盖导航、交互提示、无障碍名称、79 课正文与动态讲解、9 个综合专题、37 道练习题与题解、实现接口说明和伪代码。
- 用户输入、私人笔记、课程 ID、选项值和数值快照保持原样。真实 TypeScript 引擎源码入口按原文件展示，避免把翻译后的程序字符串误当作实际运行源码；JavaScript/Python 核心实现的教学注释提供英文，复制内容与显示一致。
- 讲解翻译后再测量分页；图形文本按翻译后长度计算边界；用途标签、原始输入条目先翻译再拆分。搜索支持英文课程用途、题目标题与描述。

## 工程与维护

- 使用应用级 JSX runtime 在 React 接管 DOM 前翻译可见文字与 aria/title/placeholder 属性，避免 DOM 后处理造成渲染不同步。运行时不依赖翻译 API、网络或账号。
- `src/i18n/source.json` 的稳定索引对应 `en.ts`。`composed.ts` 补充组合文本及教学代码注释；占位符保留、嵌套值递归翻译，内部标识符不变。
- `npm run i18n:extract` 收集新增文本，已有 ID 不重排；`npm run i18n:check` 在新增文本未收录时失败。单元测试要求词条齐全、英文无残留中文、插值槽完整，并遍历课程数据、练习、实现和两种场景的实际动态轨迹。

## 调试记录

- 发现并修复伪代码由箭头文本转为编号段落后的翻译遗漏、用途拆分造成的片段遗漏、原始输入先截断后翻译，以及节点无障碍名称的模板歧义。
- 本地数值检查通过 314 项；完整 Transformer 反传轨迹使全参数测试超过旧 5 秒上限，将该穷举测试单独设为 30 秒，其余测试时限不变。
- 真实换向动画会短暂同时保留退出和进入的连线；浏览器断言定位当前高亮边，保留真实运动。
- 小屏反传增加三类数值后出现高度不足，观察面板调整为 250px；详情使用已有自适应分页组件。说明页末尾滑块的 thumb 超出 10px 轨道 3px，轨道改为 16px，保留全部可见内容。
- Browser plugin not available：使用项目已有 Playwright 与本机 Chrome，检查桌面/手机模拟视口及 1366×600、360×640 短屏。并非实体移动设备验收。
- 追加开发服务器检查发现：Vite 的 React 插件强制预构建自定义 JSX runtime，造成语言状态被复制。将应用 runtime 从强制预构建清单移除，React 自身仍预构建；开发服务器与生产预览都增加暂停计算中切换语言的桌面/手机回归，确认当前步骤和梯度值不变。CI 同时执行生产与开发模式检查。
