# Stage 006 · 单屏图解实验台

2026-10-31。目标：实验一屏呈现，无内部滚动；初始数据按需要嵌入图示，不再单独占区。

## 设计与实现

- 移除 Stage 005 的 1140px/1230px 固定长实验区、独立输入上下文区、重复的实验方法栏与可滚动缩放图。
- 桌面采用主画布 + 讲解侧栏；手机采用主画布 + 紧凑说明卡。实验台外部高度由可用视口决定，章节与其他课程内容继续保持挂载。
- 画布顶部显示必要输入参照（树/结构的构建序列、字符串原文），中间展示状态，底部展示真实工作列表。图算法不重复列输入边；全部输入可在“数据”查看。Huffman 原文始终位于画布内，频次直接见节点和数据明细。
- 使用 ResizeObserver 同时拟合场景宽高；图、条形图、矩阵与序列共用自动适配。默认没有平移/滚动容器；专注模式调用浏览器全屏，退出后恢复，原有动效仍保留。
- 讲解按“这一步、详解、数据、结果”切换，长文字与表格分成可前后翻页的卡片。完成帧自动打开结果；点击图中元素打开数据详情。初始输入与工作列表超过一行时可逐页读取，多个工作列表用选择器切换。
- 播放、步进、重置、时间轴和速度固定在画布下方。关键节点从滚动按钮列表改为下拉导航，保留关键步骤暂停模式。

## 验证发现与修正

- Browser plugin not available，使用仓库 Playwright 与已安装 Chrome。桌面检查 1536×1024、1366×768；手机手工截图为 390×844，Playwright iPhone 13 配置的实际 viewport 为 **390×664**（screen 为 390×844）。本阶段按实际可用 viewport 验证，不将 screen 大小误记成 viewport。
- 首轮短屏发现空树场景可用高度为零时仍保留 scale=1，图层遮挡讲解模式开关。修复零空间缩放，并加入短屏布局：省略重复章节标题、缩短说明分页、释放画布空间。验证通过实际 elementFromPoint 命中检查，不以隐藏滚动条替代适配。
- 首轮数组结果的多行 JSON 及两行码表超出短屏说明卡；结果改为紧凑表示并按视口分页，短屏码表逐行阅读。全部内容可通过下一页访问。
- 矩阵场景首帧未测量的 680px 自然宽度曾短暂扩张手机 layout viewport，造成章节定位偏移；初始 scale 改为 0，图示视口隔离未拟合的绘制溢出，并对最终拟合后的场景宽高与控件命中独立断言。
- 测试新增：实验台完全处于视口、画布宽高均适配、说明每页无溢出、控制未被遮挡、全屏进出、Huffman 编码结果可读。全目录 A/B 首中尾检查同时断言没有实际内部滚动容器且正文坐标保持稳定。

## 验证与发布

本地 290 项单元/性质测试、TypeScript 与生产构建通过。最终完整 28 项桌面/手机浏览器回归全部通过；新增测试对 Huffman、拓扑排序、背包与 AVL 逐页检查文字容纳、真实控件命中和最终输出。桌面/手机最终截图已查看，控制与讲解在单屏内，图形完整适配。首次独立 CI 的 27 项浏览器用例通过，唯一失败为退出全屏的即时断言：Linux 上退出异步完成，测试过早读取 fullscreenElement。改为等待真实退出状态与按钮恢复，本机该用例复验通过；应用逻辑未变。最终 CI 与发布结果待追加。
