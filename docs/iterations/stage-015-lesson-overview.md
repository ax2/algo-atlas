# Stage 015 · 先看整体，再看单步

## 问题与目标

实验台原先默认解释当前帧，初学者不容易知道输入要变成什么、正在解决哪个问题。本轮为全部 79 课补充专属任务、三步整体路线与完成核对，不把抽象定义当成示例目标。

## 实现

- 课程标题之后显示「本例导览」，完整呈现任务、路线与完成标准；按钮滚动到实验并把键盘焦点交给播放控件，不自动开始。
- 导览位于固定高度实验台外，播放不会改变其高度或挤压画布。实验起点默认选中「总览」，复用测量排版与分页，只有空间不足才翻页。
- 总览使用已应用输入与当前轨迹的 source、起始帧说明；搜索另列目标。未提交或校验失败的输入不会冒充当前实验数据。
- 播放、前后单步、拖动时间轴或关键节点跳转时进入逐步讲解；点总览会暂停并保留帧位置。重置和应用输入重新打开总览；有步骤的分享链接保留原位置。
- 整体路线描述算法思路，不伪装成等分时间轴；循环可以多次执行同一步。当前帧标题与步数继续给出实际位置。
- 导览沿用现有主题、中英词条和响应布局，没有新增运行时依赖。

## 内容核对

以实际引擎轨迹而非独立代码实现为依据，逐课核对任务和过程。例如：Huffman 包含建树、码表、编码与解码；链表动画是尾部构建后删除第二项，不是代码示例中的反转；二分查找返回排序后位置且不保证最左重复项；A* 当前 h=0；小根堆包含一次弹出；LCS 只返回长度；注意力单课不含掩码或训练。
