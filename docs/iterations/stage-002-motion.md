# Stage 002 · 光影与运动语言

2026-10-30，依据用户对“连线不突然出现/消失，带加速与光影，其他元素同等动效复杂度”的追加要求。

## 已实现

- 连线保留 from/to 身份，进入时沿路径加减速绘制，退出时逆向收束并淡出。
- 光晕层、线芯层、沿线光粒分离；活动边重放一次传导，不使用无限闪烁。
- 节点位置与连接端点使用一致缓动；节点有入场惯性、局部轮廓波纹、顶部反光与数值过渡。
- 排序柱体按数值及重复序号追踪，换位时横向移动；高亮时叠加扫描光与边缘辉光。
- 矩阵值更新采用小范围位移/模糊收敛，热点单元有边框光波；线性单元有 FLIP 布局过渡和扫光。
- 播放速度与过渡时长联动；光影按钮允许关闭，系统 prefers-reduced-motion 优先。
- 阅读页签切换时保留实验位置，避免解释回来后丢失上下文。

## 验证结果

- 算法、存储、边界与跨算法对照共 36 项测试通过；TypeScript 与生产构建通过。
- 桌面 1536×1024、移动端 390×844（Chromium 模拟）共 10 项浏览器回归通过。边绘制采集 18 个中间样本，确认路径长度从 0 到 1；退出时确认元素先保留、随后移除。
- 验证光影关闭、动态切换系统减少动画设置、5× 播放到终点、排序元素数量、阅读页签返回保留步骤；浏览器流程无 pageerror。
- 修复系统偏好运行中变化未生效：以 matchMedia 订阅替代仅初始化读取。
- 截图等待 Motion 的 requestAnimationFrame 过渡结束，避免将入场中途误作最终静态画面。
- 实际浏览器录制覆盖凸包边进退、排序换位、LCS 单元更新、AVL 结构变化；录制只是功能证据，不代表真人课程或所有设备验收。

## 交付边界

光影可关闭，系统减少动画优先。高倍速自动缩短过渡；教学快照、数值和复杂度推导不因特效改变。CSS 模糊/滤镜在低端设备上可能有性能差异，未做真实手机帧率基准。
