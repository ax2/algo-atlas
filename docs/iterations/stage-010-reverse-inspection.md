# Stage 010 · 数值反向联动与计算过程

## 目标与实现记录

- 点击张量单元格、联动权重表或参数账本数值，反向定位节点与连线；在原观察面板内展开推导。返回时保留张量、分页和键盘焦点。
- 主图下的更新区按旧值、梯度/−TD、学习率、新值四项展示，标记所选字段与实际写入值。跨反传/更新阶段保留参数身份，明确预览和已写入的区别。
- 通过稳定张量引用和行列映射保留原始样本、特征、状态动作坐标，不解析显示文字。
- 神经网络解释乘加、偏置、tanh/sigmoid 与稳定交叉熵；Transformer 解释 LayerNorm、Q/K/V 投影、缩放点积、因果掩码、稳定 Softmax、残差、前馈和词表输出。
- 参数被点选后重建当前更新前的小模型，收集真实反向传播中该参数每次被使用时的上游梯度、局部导数与贡献。只保存数值解释，不向回放帧注入计算图。
- Q 表解释 TD 目标、终止状态不自举、方向与更新等式；未在本步更新的单元格可回溯最近一次历史写入，并明确历史身份。
- 点击不同样本的神经网络张量时，图中输入与已计算激活同步到该样本；尚未计算的后续激活不会提前出现。Q 状态字幕显示所选动作值，避免误读成当前策略的最大 Q。

## 关键调试

- 推导展开时表格暂时隐藏。最初 ResizeObserver 将隐藏尺寸当成一行一列，清掉检查状态；改为忽略零尺寸，保留原表格位置。
