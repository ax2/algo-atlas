# Stage 011 · 计算过程动态回放

## 目标与实现记录

- 在原数值推导面板提供“逐步演示 / 完整推导”切换；逐步播放、暂停、前后单步、重新开始和进度拖动独立于训练时间轴。
- 复用真实 Scalar 运算图，按读取、乘加、激活、反传贡献累加、学习率乘法与写入快照生成微步骤。公式的数值与单元格通过稳定 ID、原始张量坐标和颜色对应；本步最多四项，不把矩阵整体塞入窄面板。
- 主图同步相关节点和边；神经网络乘加区分具体输入连接，反传沿反向连接，输入与激活随贡献所属样本切换。中间结果显式标记“本步”，权重连线展示贡献/累计梯度/参数值。
- Transformer 支持投影、缩放分数、掩码、Softmax、残差、ReLU 前馈及词表输出；内部临时量以 t 标记，命名张量作为可追溯输入边界。
- 强化学习分解折扣未来值、TD 目标、−TD 方向、学习率与 Q 写入；终止状态不自举。保留写入预览及历史回放身份，回放不会再次训练。
- 固定视口中保留图、更新等式、微步骤控制、公式和参与计算的单元格。空间充足显示步骤说明，短屏可切回完整推导阅读全部解释。未新增内部滚动容器。

- 修复后四项专项浏览器场景全部通过；已查看桌面 ReLU、短屏 Q 更新、手机 NN 更新和窄屏 Q 更新截图。
- 310 个数值/算法测试、TypeScript/Vite 生产构建通过。新增六项数值检查遍历每个可见张量单元格，核对每步公式引用、乘加结果、梯度累加、未来数据隔离和 Q 历史写入。
- Browser plugin not available：沿用项目 Playwright + 本机 Chrome，没有新增依赖。桌面 1536×1024、手机 390×664，附加 1366×600 和 360×640 视口；这属于自动化与模拟视口检查，不是真实手机验收。
