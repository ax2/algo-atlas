# Stage 009 · AI 图示与数据联动

## 目标与进行中记录

- 节点/连线使用稳定语义 ID 关联真实张量和参数，不解析显示文案或假造梯度。
- 节点默认展示对应激活，连线优先展示具体权重/相关算子的权重梯度；当前参数等式同步筛选。
- 只暴露当前阶段已计算的数据。更新帧保存重新前向评估的激活与更新前快照；梯度仍来自更新前的反传。
- 更新值采用持久标记与短暂脉冲；Q 表保留写入前数值，定位实际状态动作对。低动态模式保留静态标记。
- 延用固定视口、张量行列分页与说明真实高度分页，验证跨页联动和桌面/手机几何。

## 已实现的行为

- 新增“联动”观察面板。节点默认展示其激活，神经网络连线精确绑定 W1/W2 的单个元素；隐藏节点关联入边、偏置与出边。Transformer Q/K/V 选择同步筛选 WQ/WK/WV，算子连线关联对应参数组。
- 相关权重表列出更新前、梯度、更新后/预览。点击参数行同步主图下方的等式，点击数值可看旧值与当前值；变化色保留到离开当前更新帧，另配短脉冲。
- SGD 后激活通过新参数重新前向计算；旧激活快照供比较，梯度仍对应更新前的损失。未到达阶段的张量与梯度显示“待计算”，不提前泄露后续结果。
- Q 表自动翻到当前状态动作项，橙色框定位写入位置，绿色标出实际变化。图上标记更新来源状态，智能体仍停在环境反馈的下一状态；两者不会混淆。目标阶段的新值明确为预览。
- 张量、参数账本继续按实际可用空间分页；所有数值可访问，无内部滚动条。键盘可选节点与连线，减少动态效果时保留静态变化标记。

## 调试记录

- 补齐节点 Enter/空格的结构化选择回调，避免鼠标与键盘行为不一致。
- 神经网络交叉连线的中点会命中其他线段；保留真实命中行为，增加悬停提示/描边，浏览器验证选择实际无遮挡线段，而非人工派发事件。
- 阶段推进时可用张量数量会增加；改为按稳定名称保留选择，防止“权重对照”错位成 K 张量，并保留同一张量的分页位置。
- 返回联动面板时同步重置张量和参数组，避免画面显示 Q 却沿用 K 的参数筛选。
- 零增量 Q 更新保留位置框，不标记虚假的数值变化；注意力概率和 Q 更新方向分别注明其语义。
