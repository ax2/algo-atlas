# Stage 013 · 英文内容与排版审查

## 范围与改动

- 英文模式覆盖展开后的源码，不再把整个引擎源码区域排除在翻译检查外。9 份 TypeScript 源码通过 AST 生成英文教学视图，翻译教学字符串、模板与展示标签；注释同样要求无中文残留。界面明确说明它是本地化视图，复制内容与显示相同，GitHub 仍可查看原文件。
- JavaScript/Python 的教学注释已参与英文执行验证：逐项执行全部公开样例，结果与中文实现一致。37 道独立题目的提示、完整题解与 TypeScript 参考实现继续纳入浏览器扫描，79 课的课内正误反馈亦展开检查。
- 提取器新增中文标识符扫描，补齐 37 个独立统计词条，例如总流量、候选不纯度、当前长度；另把轮次跳转改为完整词组翻译，避免 `Jump toepoch`。词条总数为 2954。
- 输入和说明分页优先停在英文单词边界；长位串与无空格标识符仍允许拆分，保证每个字符可达。没有通过隐藏溢出或截断正文掩盖问题。
- 长图节点标签拆为两行，边界计算使用最长行宽；手机 AI 图保留水平节点间距，避免压缩后节点相碰。计算步骤标题允许换行；窄面板的播放按钮保留可访问名称与图标，给层级名称腾出空间。
- 修正普通演示滑块超出轨道的空间，以及长英文工作区标题把计数桶内容挤出画布的问题。工作区自然换行，主图自适应余下空间，实验台总高度固定。
- 移动端调度专题的长英文比较结果原本继承过大的行距而超出比较区；改用适合多行指标的行距，不减小字号、不截断结果。

## 检查流程

Browser plugin not available：使用项目 Playwright 与本机 Chrome。目标流程为英文课程/专题 → 修改阶段或场景、展开实现/题解、翻页 → 无遗漏、控件可操作、无页面异常、实验区一屏无内部溢出。桌面与手机模拟视口另覆盖 1366×600、360×640 短屏；不将模拟视口称作实体设备验收。

- 逐课打开 JavaScript、Python 与引擎源码，并点击所有课内选择题选项。
- 79 课检查初始、中段、结束的四类讲解；末帧遍历全部说明、数据及输出分页。静态/数值检查另遍历所有默认轨迹和两种内置场景的动态字符串。
- 六个常规综合专题检查两个场景、完整解释及全部说明分页；三个 AI 专题检查所有训练阶段和图节点重叠。
- 继续覆盖英文 Q 更新、明暗主题、所有独立题解、语言切换持久化、暂停计算时切换语言，以及短屏反传逐步说明。

## 维护

`npm run i18n:extract` 后补齐 `en.ts`，再运行 `npm run i18n:source` 更新英文源码视图。`npm run i18n:check` 会拒绝遗漏词条或过期源码；源码不能安全转换或有残留中文时生成器会报错。生成文件不是独立维护的另一套算法。
