# Stage 005 · 单页课程、实现与演示语义

2026-10-31 开始。用户要求：全部数据结构/算法增加多语言实现与伪代码；审查演示完整性；课程单页完整展示且播放不扰动其他内容；练习入口保留当前算法。

## 设计与发现

- 79 个单元各提供 JavaScript ES2022、Python 3 核心实现、独立调用样例与简洁伪代码。明确接口、输入前提与实现范围，不用轨迹生成器充当可复制算法。
- 实现采用同一合同的两种语言，自动执行样例并交叉核对；只展示受信任的项目代码，不引入用户代码沙箱。
- 章节改为页内导航，正文/复杂度/实现/练习一直存在。实验区域约束画布和动态说明高度，播放不推动下面的正文。
- 已发现拓扑排序说明使用完整队列而非未消费队列；Huffman 只输出码表、没有逐叶码字及原文编码/解码过程；最大流 BFS 和 SCC 栈缺少可见辅助状态。
- 逐帧结构/算法测试保留；新增过程状态、输出语义、两种实现执行、单页布局稳定性、课题筛选与返回路径验证。

## 实现与审查发现

- 全部 79 个单元各有两份独立实现（158 份），按 8 组源文件维护；共享的注册表定义伪代码、输入前提、样例和期望输出。JS 与 Python 使用同一接口合同；语言切换、复制时附独立调用代码。两种语言在本地和 CI 实际执行，不在浏览器运行任意用户代码。
- 五个章节始终挂载，章节导航为滚动按钮并固定在页顶；读原理或代码时，演示状态与复杂度滑杆都保留。画布、输入工作区与讲解栏有固定外部尺寸及内部滚动，避免图/矩阵、长解释、最终输出使下方正文跳动。打印解除高度限制。
- Huffman 每帧保留原文和频次；森林最小候选、根到叶码字、逐字符编码、逐位解码均来自真实状态。最后自动展示码表、完整位串、恢复原文和往返校验；单字符约定为 0，压缩对比明确未计码表开销。
- 拓扑排序改用未消费队列，逐条删除依赖、入度归零后入队。BFS/DFS、最大流残量 BFS 展示实际队列/栈与已访问集合。最大流图中的数值随残量更新，包含反向残量；先展示瓶颈，再执行增广。SCC 显示递归调用栈、原图退出序列和反图扩展。
- Dijkstra / A* 明确显示线性扫描候选集（未伪装为堆），补前驱路径还原。A* 动画仍是 h=0 基线；独立实现可传入一致启发式，范围和成本已注明。
- 审图发现 SCC 和残量网络的相反方向边重叠；双向边改为分离的二次曲线，权重随各自曲线定位，箭头沿终点切线，光粒沿同一路径加速运动。
- 补堆弹出最小值/末尾补根/下沉，普通线段树区间查询、懒标记查询分支、持久化树逐节点复制与回填。BST/B 树显示下降选择。Fenwick 和并查集补当前输入上下文。
- “递归与记忆化”原动画只是自底向上递推；本次改为真实递归调用、缓存命中、写缓存和返回栈，两种实现同步采用记忆化。归并显示剩余缓冲区；插入排序显示暂存值；计数/基数排序显示桶；单调栈显示下标和值。
- 修正长度为 2 的滑动窗口仍写“长度为 3”的说明。背包/贪心/皇后/跳表的原始场景数据改为具体清单。末帧统一引导核对结果，不再预测不存在的“下一步”。
- 课程入口及侧栏练习入口都携带 topic；筛选器包含所有课程，不能因该课暂无独立题目而误显示“全部专题”。题目详情返回保持课程筛选。

## 验证过程

- Browser plugin not available；沿用仓库 Playwright 与本机已安装 Chrome，桌面 1536×1024、移动模拟 390×844（非真机）。
- 首次 Python 执行发现 Windows 标准输入默认编码差异，测试运行器显式 `-X utf8`，并在 CI 固定 Python 3.12；没有绕过 Python 实际执行。

- 新增浏览器验证所有章节同时存在、切换语言/复杂度不丢状态、播放首中尾后章节文档坐标变化小于 1px、所有课程练习跳转及图/矩阵切换不移动正文。截图放会话 outputs，供检查桌面与移动布局。
