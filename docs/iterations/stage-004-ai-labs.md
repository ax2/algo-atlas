# Stage 004 · AI 综合实验

2026-10-31。目标：神经网络训练、Transformer、强化学习三个综合专题；动态解释数据流、参数更新，附带题解训练。

## 设计与工作记录

- 使用小型真实计算模型和确定性输入，可回放不可变快照；不把装饰动效当作学习过程。
- 神经网络采用多层感知机；Transformer 采用单层双头因果模型；强化学习采用有限网格的表格 Q-learning。
- 监督训练通过标量反向自动微分计算梯度，展示更新前值、梯度、更新后值；强化学习展示 Bellman 目标与单项 Q 值变化。
- 控制项改变后从固定初始条件重算，避免把不同参数实验混在一起。复用连线光影、暂停和减少动态效果。
- 原始资料：PyTorch 优化教程、Harvard Annotated Transformer、OpenAI Spinning Up。Sutton/Barto 官方 PDF 本次工具获取失败，不据此声称逐页核验。
- 验证计划：有限差分检查梯度、掩码与概率不变量、更新合同、终止状态处理；桌面和移动布局交互回归。

## 实现与调整

- 新增 3 个实际计算专题，总数 9；算法单元仍为 79，避免重复计数。新增 9 道题，总题库 37（24 竞赛/结构 + 13 AI）。所有题解函数通过公开样例测试，新增终止、γ=0/1、ε=0/1、极端 Softmax 与梯度边界。
- MLP 13 参数；Transformer 158 参数。后者为单层双头 decoder-only Pre-LN 变体，固定位置编码与 LN scale/bias，其他列出参数参与反向自动微分（未用嵌入行梯度零）。RL 为 48 表项 Q-learning，独立于神经网络求导器。
- 初始数据、形状、神经元值/张量、每组参数更新账本、按轮跳转、关键暂停、损失/回报曲线均来自数值快照。参数/场景变更重新开始；分享 URL 还原设置和步骤，输入范围校验保护重放预算。
- 神经元图展开一个样本，平均损失和梯度仍汇总全部四个样本，界面明确标注。Transformer 反传不向优化器或离散 token 画梯度来源。
- 首轮浏览器测试捕获 Motion 的 SVG `d=undefined` 短暂错误；共享连线为初始路径显式赋值，保留加速绘制与退出动画。同步修复中文节点宽度和连线矩形边界，避免箭头穿字。
- 浏览器测试直接 import 带 Vite `?raw` 的题库导致运行器无法加载；改为从 UI 路由/状态验证，未把工具配置错误当作应用运行失败。

## 已完成数值验证

188 项测试通过：神经网络与 Transformer 的每个参数在两个场景下都用中心有限差分验证梯度；共享路径累加/重复反传清零；两个头概率归一化、未来 token 不影响此前输出、残差和 V 加权数值；跨轮参数连续性；不同 ε/γ 下逐次 Q 更新与独立环境结果一致。

本机默认配置观察：MLP 40 轮损失约 0.6951→0.6316；Transformer 8 轮约 1.1409→0.3797；Q-learning 16 回合后贪心评估 0→1→5→9→10→11 到达终点。这些是教学小数据结果，不是泛化、收敛或硬件性能证明。

前端采用 frontend-testing-debugging 与 React best-practices 技能。Browser plugin not available，沿用仓库 Playwright / 已安装 Chrome；桌面 1536×1024、移动布局 390×844。全量 20 项浏览器回归通过，包含旧 79 课与三个 AI 实验；新实验标题/路由正确、无空白/框架错误遮罩，控制台 error/warning 与 pageerror 均为零。已验证场景与步长重置、关键暂停、轮次/阶段跳转、张量单元检查、参数组、结束状态、分享还原、减少动态效果及题解往返。截图存会话 outputs，不把模拟视口称为真机。
