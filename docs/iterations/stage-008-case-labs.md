- 将三个 AI 专题的主图、讲解、张量、参数更新和设置收进固定视口的实验台。
- 复用 Stage 007 内容边界缩放与真实排版测量分页，避免缩成难以阅读的长表或出现内部滚动条。

## 布局与交互

- AI 主图占满可用区域，按节点、字幕和边界缩放。小屏缩紧节点间距，保留连线方向和光影动画。
- 讲解 / 张量 / 参数 / 趋势 / 设置共用观察面板。曲线模式在主画布显示历史趋势，侧栏给出解释与完整数值；分享链接在面板内单独显示。
- 主图下方的参数聚焦区允许选参数，默认关注绝对梯度最大的条目。反向阶段明确标记“更新预览”，写入后标记“已更新”。前向阶段标记参数保持不变，尚未计算的梯度不伪装成已算出的零。
- 讲解沿用字体与真实 DOM 高度测量：整段能放下就完整显示，溢出时才拆段/表格。张量按实际宽高分页，行列索引保持原值，点击显示完整精度；参数按组筛选、完整分页。
- 桌面左右布局，小屏上下布局；阶段选择、回放、速度、跳轮、关键步骤暂停固定在实验区内。可进入原生全屏专注模式。
- 六个普通综合专题仍是实际计算的方案比较，不将结果摘要冒充完整算法动画；将流程、约束选择、结果和过程记录放入同一个固定视口。

## 调试发现

- 第一版手机播放控件沿用旧的上下留白，导致主图过小；移除旧留白，压缩面板标题和节点间距。
- 小屏固定展示完整张量会溢出；新增按高度计算行数、按宽度计算列数的观察窗，不裁掉不可见数值。
- 长参数表不能单靠 overflow 隐藏；沿用表格分页并验证跨页记录的完整性。
- 浏览器与 Node 的数学库可能在最后一位产生 1 ULP 差异。完整精度检查使用 1e-12 量级比较；界面四位小数账本逐项精确比较。
- 分享文本框的长 URL 可以原生选取和复制，不属于内容区域滚动条；布局检查验证其外框，并排除原生输入文本的内部宽度。
